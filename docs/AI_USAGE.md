# AI usage

## Summary
Most of the code, tests and documentation in this repository were generated by AI coding agents in VS Code. I directed the work with written prompts, ran checks myself where I could, and reviewed the agent's audit reports. I also used a separate AI chat assistant (Claude) to plan the approach, draft those prompts, critique the agent's reports and draft the README.

## Tools used
- Coding agent in VS Code: Chat gpt Luna 6 The agent may have used subagents; I cannot see their prompts.
- Claude (chat): planning, drafting prompts, reviewing the audit output 

## Where AI accelerated my work
- Designing the data model, rules and anomaly-injection approach (planning with Claude).
- Generating the generator, validator, detector, forecast, exports, tests and docs (coding agent).
- The audit work: an independent standard-library checker, reproducibility check and fresh-clone test (coding agent, from my prompts).
- The optional dashboard, generated by the coding agent from a design spec drafted with Claude.


## What I personally did
- Ran the prompts in order (core build, audit, hardening, final fixes, dashboard) and pasted the agent's reports to Claude for review.
- Created docs/PROBLEM.md by pasting the brief.
- Decided to build the dashboard only after the core was pushed and safe.
- Ran commands myself: pytest, ruff, generate, validate and detect on the starter data; a clean-clone build of the dashboard; pushed to GitHub and watched the CI.
